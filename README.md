# Telegram-бот: рассылка + маркет номеров

Бот на **Python + aiogram 3** (режим polling, без сервера и домена).

## Возможности

- 🛍 **Маркет**: `/store` — каталог номеров (флаги, коды, цены), кнопка
  «Купить» открывает ЛС продавца с готовым сообщением
- ⏰ Ежедневные напоминания по расписанию (`NOTIFY_TIMES` в `.env`)
- Рассылка всем подписчикам: `/broadcast <текст>` (только для админа)
- Подписка/отписка: `/sub`, `/unsub`, `/status`
- Мини-приложение (Telegram Web App) — готово, подключается при наличии
  HTTPS-хостинга (см. ниже)
- Подписчики хранятся в SQLite (`subscribers.db`)

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установи зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. Настрой окружение:

```powershell
Copy-Item .env.example .env
notepad .env
```

Впишите `BOT_TOKEN`, `ADMIN_ID` и при желании `NOTIFY_TIMES` (например `09:00,18:00`).

## Запуск

```powershell
python bot.py
```

## Примеры

```
/start            — регистрация и приветствие
/sub              — подписаться
/broadcast Всем привет!   — админ: рассылка всем подписчикам
/stats            — админ: статистика
```

## Товары

Редактируй список `PRODUCTS` в `store.py` (название, флаг в начале имени,
код страны, цена). После правки перезапусти бота.

## Мини-приложение (Telegram Web App)

Готовое приложение лежит в `webapp/` (страница каталога с кнопками покупки).
Telegram требует HTTPS и доступ с телефона, поэтому нужен статический хостинг.

Собрать статический файл с вшитыми товарами:

```powershell
python gen_static.py        # -> webapp/catalog.html
```

Выложи `webapp/catalog.html` на любой статический HTTPS-хостинг
(GitHub Pages, Vercel, любой файловый хостинг с инлайн-HTML) и впиши адрес:

```
WEBAPP_URL=https://твой-адрес/каталог.html
```

После перезапуска у `/store` появится кнопка «Открыть каталог (приложение)».
Для разработки локально: `python webapp.py` (порт 8080).

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | команды, обработчики, запуск polling |
| `store.py` | товары, карточки, ссылки «Купить» |
| `scheduler.py` | ежедневные уведомления + рассылка |
| `db.py` | подписчики в SQLite |
| `config.py` | чтение `.env` |
| `webapp/index.html` | мини-приложение (шаблон) |
| `webapp.py` | локальный dev-сервер приложения |
| `gen_static.py` | сборка статического каталога |
